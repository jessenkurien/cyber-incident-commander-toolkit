# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub’s private vulnerability reporting feature for this repository. Include the affected component, reproduction steps, impact, and any recommended mitigation.

Do not include real credentials, tokens, personal data, customer data, proprietary indicators, or active-incident evidence in a report.

## Supported version

The latest version on the `main` branch is supported.

## Operational disclaimer

This project is an educational and portfolio toolkit. Organizations remain responsible for validating all procedures against their incident response plan, technology environment, legal obligations, evidence requirements, and risk appetite.
